# Ishwar Premium Portfolio

Premium dark/neon-blue personal portfolio built with React + Vite.

## Frontend
- Home
- About
- Skills
- Projects
- Project Detail
- Experience
- Contact
- Dark/Light theme toggle
- Responsive premium UI
- Montserrat typography
- React Icons

## Admin
- `/admin/login`
- Dashboard
- Home
- About
- Skills
- Projects
- Experience
- Contact
- Inquiries

Admin credentials:
- Email: `Ishwarweb@admin.com`
- Password: `AdminIshwar@1234#`

## Run
```bash
npm install
npm run dev
```

Alternative:
```bash
npm start
```

Production build:
```bash
npm run build
```

The supplied Ishwar profile image is stored at `public/assets/ishwar-profile.jpg` and used throughout the portfolio hero sections.
